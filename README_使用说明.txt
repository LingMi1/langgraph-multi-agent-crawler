网站爬取工具 v1.1 使用说明

==============================================

支持平台：DeepSeek / SiliconFlow / Moonshot / 智谱 / 通义千问 / OpenAI 及各类兼容 API

==============================================

1. 获取 API Key（以 DeepSeek 为例，免费送 1000万 tokens）：

   点击软件中的「🔗 获取 Key」按钮，或访问：
   https://platform.deepseek.com/api_keys

   注册账号 → 创建 API Key → 复制 sk- 开头的字符串

2. 配置 API：

   选择平台 → 一键填入地址和模型 → 粘贴 Key → 点击「💾 保存配置」
   （下次打开软件会自动加载，无需重复输入）

   也可以手动输入其他兼容 OpenAI 格式的 API 地址和模型名。

3. 准备网址文件：

   创建 .txt 文件，每行一个网址（http:// 或 https:// 开头），最多 10 个
   # 开头的行为注释，空行自动跳过
   参考 urls_example.txt 格式

4. 开始爬取：

   点击「浏览...」选择 TXT 文件 → 点击「🚀 开始爬取」

5. 查看结果：

   结果保存在程序目录下的 output/公司名/ 文件夹中
   按网站导航栏层级组织，方便浏览

==============================================

注意事项：
- 请确保网络连接正常
- 爬取过程中请勿关闭软件
- API Key 保存在本地 config.json 中，请勿分享给他人
- 如遇爬取失败，请查看日志区域的错误信息
