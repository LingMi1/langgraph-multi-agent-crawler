输入框样式对比 · 深色专业工具主题

为桌面工具（pywebview / WebView2 嵌入）选型。4 种风格均为纯 CSS/HTML，动画全部由 @keyframes 与 transition 实现。悬停 / 聚焦即可看到动态效果。

风格 A

极简暗色 · 聚焦发光

灵感来源：uiverse.io/0xnihilism/tricky-cow-79

评价：低干扰、专业感强。聚焦时边框色与多层外发光以 0.35s 平滑过渡，placeholder 同时滑出，弹跳缓动曲线（cubic-bezier 越界回弹）带来轻量灵动感。适合主搜索框 / URL 输入框。

风格 B

终端 · 赛博朋克

灵感来源：uiverse.io/aboalsim114/selfish-fly-63

评价：原生深色 + 霓虹绿边框持续"呼吸"发光（@keyframes 2.4s 循环），左侧 ❯ 提示符 1s 步进闪烁模拟打字光标。悬停时暂停呼吸、轻微 3D 倾斜。终端感拉满，适合日志路径 / 命令行式输入。

❯
风格 C

新拟物暗色 · 按下凹陷

灵感来源：uiverse.io/adamgiebl/lucky-donkey-6（按压范式）+ 深色新拟物配方

评价：双向明暗阴影营造"从背景中浮起"的立体感。聚焦即从凸起凹陷为 inset（凹陷动画），按下时再加深并轻微下沉 1px，触感明确。无边框、极安静，适合表单主区域 / 设置面板。

风格 D

玻璃拟态 · 悬停变焦

灵感来源：uiverse.io/SteveBloX/dangerous-warthog-85 + soft-baboon-75（backdrop-filter 用法）

评价：半透明底 + backdrop-filter 毛玻璃，悬停时模糊度从 6px 平滑升至 16px（背景光斑随之化开），边框与亮度同步增强，聚焦再升至 20px。最有"漂浮感"，适合覆盖在彩色图表 / 数据可视化之上的浮动输入。

说明：风格 A / B 基于 uiverse 真实输入框组件深色化改造；风格 C / D 因 uiverse 无现成深色输入组件，采用"uiverse 灵感来源 + 自研组合"。全部动画均为纯 CSS。pywebview 使用 WebView2 内核，backdrop-filter 可完整生效。
